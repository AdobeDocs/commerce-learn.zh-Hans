# 批量数据迁移工具简介

准备Docker并访问批量数据迁移工具以将Adobe Commerce数据迁移到[!DNL Adobe Commerce as a Cloud Service] ([!DNL ACCS])。

## 此视频面向谁？

* 解决方案架构师
* DevOps工程师
* 后端开发人员

## 视频内容

* 了解批量数据迁移工具的功能和限制。
* 在启动之前，请确认Docker已安装，并且Docker引擎正在运行。
* 提取工具包并设置正确的文件夹权限。
* 查看此系列后续视频中配置的`.env.example`文件。
