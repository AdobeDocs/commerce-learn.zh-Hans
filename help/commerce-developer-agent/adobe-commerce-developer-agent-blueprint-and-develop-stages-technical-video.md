# Adobe Commerce Developer Agent Blueprint和开发阶段

在Blueprint和开发阶段，纯英语规则变为可正常使用的验证代码。 以购物车数量限制为例，Adobe Commerce Developer Agent将描述的规则转换为您可以查看的正式计划，然后在实时工作区中编写并自行验证webhook代码。

## 此视频面向谁？

* Commerce开发人员
* 解决方案架构师
* 后端工程师

## 视频内容

* 以纯语言描述业务规则（购物车数量限制）并在App Builder模式下生成Blueprint
* 审查Blueprint和计划面板 — 运行时选择、企业准备工作清单和置信度评估
* 计划分解为具体任务，以及webhook如何评估和阻止购物车添加的逻辑图
* 开发阶段在项目工作区中写入代码，并将文件和代码流式传输到项目资源管理器中
* 自动构建、测试和自校正，代理在需要澄清时暂停询问
* 验证生成的配置、业务配置架构和webhook详细信息
