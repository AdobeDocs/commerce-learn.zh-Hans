# Adobe Commerce Developer Agent配置和测试

安装应用程序后，其限制和消息将成为任何人都可以调整的业务设置 — 无需代码。 此阶段会配置购物车数量限制，并在店面中测试购物车数量以确认规则是否有效。

## 此视频面向谁？

* Commerce开发人员
* Commerce管理员
* 促销商

## 视频内容

* 查看代理公开的业务配置 — 最大购物车数量和面向购物者的消息
* 将每个SKU的最大购物车数量从默认值降低到较低值并保存，而不更改代码
* 在店面中添加产品并超出配置限制
* 确认块和确切的错误消息，无需重新部署即可强制上线
