# Adobe Commerce Developer Agent连接集成

生成的代码需要一个运行位置以及到存储区的连接。 在启用该功能之前，此阶段会集成所有内容 — 在App Builder中托管代码，将其连接到您的Adobe Commerce实例，以及链接GitHub存储库。

## 此视频面向谁？

* Commerce开发人员
* 解决方案架构师
* 后端工程师

## 视频内容

* 创建App Builder项目和工作区，以托管开发人员代理创建的代码
* 观看代理为项目搭建基架，并显示未完成的设置项
* 在开发人员控制台中添加所需的Adobe Commerce as a Cloud Service API凭据
* 将代码连接到特定的Adobe Commerce云服务实例
* 要存储和版本代码，请链接GitHub存储库
