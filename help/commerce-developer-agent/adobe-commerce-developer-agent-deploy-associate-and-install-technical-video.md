# Adobe Commerce Developer Agent部署、关联、安装

连接一切后，应用程序即可投入生产。 此阶段将部署代码，然后将它关联并安装在Adobe Commerce管理员中，以便在该应用商店中启用新功能。

## 此视频面向谁？

* Commerce开发人员
* 解决方案架构师
* Commerce管理员

## 视频内容

* 要求开发人员代理从聊天中部署并确认确切的组织、项目和工作区
* 部署前验证阶段，然后在部署代码时流式处理构建和发布输出
* 从Commerce管理员的“应用程序管理”屏幕将已部署的应用程序关联到特定商店
* 查看应用程序信息卡 — 名称、版本及其添加的功能(webhook)
* 安装应用程序以激活该功能并确认已成功安装
