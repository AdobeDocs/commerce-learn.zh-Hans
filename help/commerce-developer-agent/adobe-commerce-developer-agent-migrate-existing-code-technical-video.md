# Adobe Commerce Developer Agent迁移现有代码

并非每个项目都从空配置开始。 此示例使用迁移评估工具向开发人员代理提供信息，将现有扩展迁移到App Builder，从PaaS平台迁移到Adobe Commerce as a Cloud Service。

## 此视频面向谁？

* Commerce开发人员
* 解决方案架构师
* 后端工程师

## 视频内容

* 使用迁移评估工具扫描现有Commerce实例 — 复杂性评级、每模块影响、风险信号，以及重建、重构、替换或删除推荐
* 审查高影响力模块的评估，包括其挂接、文件和简单语言摘要，该摘要可加倍作为现成的提示
* 将评估直接发送到开发人员代理，无需手动复制
* 要集中精力完成特定功能的第一轮测试，请回答代理的设定范围问题
* 使用架构图生成同步Webhook的Blueprint，以替换风险最高的旧逻辑
* 使用与每个处理程序一起编写的匹配测试文件构建实施
