# 导航存储配置和系统菜单

浏览Adobe Commerce管理工作区，从筛选产品属性到自定义产品网格和保存视图。 此视频还介绍了[!UICONTROL Stores]菜单以及常规商店信息、目录设置、安全性、客户和销售的配置区域。

## 此视频面向谁？

* 管理Adobe Commerce store的管理员和用户
* 开发人员熟悉Adobe Commerce管理员

## 视频内容

* 按属性范围筛选固定的产品属性网格。
* 通过显示或隐藏列并将列拖入不同的顺序来自定义产品网格。
* 按颜色过滤产品，并将过滤的网格另存为可重用的视图。
* 在默认视图和保存的视图之间切换，并更新现有视图。
* 导航到存储配置并浏览常规、目录、安全性、客户和销售设置。

>[!VIDEO](https://video.tv.adobe.com/v/3473115?learn=on)

## 保存的网格视图

保存的视图将保留网格设置以供重用。 在视频的蓝色产品示例中，新添加的产品与过滤器匹配时即会显示。 当产品的颜色不再匹配时，将停止显示产品。

## 存储配置

[!UICONTROL Stores]菜单提供对存储设置的访问权限。 配置导览重点介绍商店位置和电子邮件地址、货币、目录显示设置、安全选项、客户默认值、配送方式和支付方式。
